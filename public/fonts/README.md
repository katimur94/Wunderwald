# Schriften

Die eigentlichen `.woff2`-Dateien liegen unter `src/assets/fonts/`, damit Vite
sie mit dem korrekten `base`-Pfad ausliefert (Dev **und** GitHub Pages).
Hier liegen die Lizenztexte zur Sichtbarkeit.

- **Fredoka** – SIL Open Font License 1.1 (`OFL-Fredoka.txt`)
- **Nunito** – SIL Open Font License 1.1 (`OFL-Nunito.txt`)

Beide Schriften sind Teil des Repos. Es wird **nichts** von Google Fonts
oder einem CDN nachgeladen.
